# 🤖 WebBrief

> **The open web, made legible.**

WebBrief is an AI-powered website summarization application built with **ASP.NET Core MVC** and **Groq AI**.

It allows users to enter any website URL and get a concise, useful summary generated by AI. Users can also choose different AI personalities depending on how they want the summary to be written.

The project is inspired by the idea of **"Reader's Digest for the internet"** — helping users understand web content quickly without reading the entire page.

---

## ✨ Features

* 🌐 Enter any public website URL
* 🤖 AI-powered website summarization using Groq
* 🧠 Multiple AI personalities
* 📝 Markdown-based AI responses
* 📊 Markdown tables rendered as proper HTML tables
* 💻 Responsive modern UI
* 🌙 Light/Dark theme support
* 📱 Mobile, tablet, and desktop friendly
* ⚡ Async website scraping and AI processing
* 🔒 API key stored through application configuration
* 🎨 Clean SaaS-style interface

## 🎭 AI Personalities

WebBrief supports four different summary styles:

| Personality        | Description                                      |
| ------------------ | ------------------------------------------------ |
| **Friendly**       | Friendly and conversational explanation          |
| **Expert**         | Precise and knowledgeable with important details |
| **Executive**      | Key takeaways and decision-relevant information  |
| **Explain Simply** | Simple explanation for a general audience        |

```text
User enters website URL

          ↓

          ↓

          ↓
Groq AI
          ↓
Generate Markdown summary
          ↓

          ↓

          ↓
```

## 🔑 Configuration

Add your Groq API key using ASP.NET Core configuration.

Example:

```json
{
  "Groq": {
    "ApiKey": "YOUR_GROQ_API_KEY",
    "BaseUrl": "https://api.groq.com/openai/v1"
  }
}
```

### Recommended

For local development, use **User Secrets** instead of storing the API key directly in `appsettings.json`.

Example:

```bash
dotnet user-secrets init
dotnet user-secrets set "Groq:ApiKey" "YOUR_GROQ_API_KEY"
```

## 📊 Markdown Support

The AI generates Markdown so the summary can contain useful formatting such as:

* Headings
* Bold text
* Lists
* Links
* Tables
* Code blocks

For example:

```markdown
### Membership Options

| Plan | Price | Highlights |
|------|-------|------------|
| Student | ₹39.99 / mo | All classes |
| Premium | ₹4,999 / yr | Unlimited access |
```

WebBrief uses **Markdig** to convert the Markdown into HTML before displaying it in the Razor view.

This allows the application to display a properly formatted table instead of showing raw Markdown syntax.

## 🔐 Security Considerations

The Groq API key should **never be committed to Git**.

Use:

* ASP.NET Core User Secrets for local development
* Environment variables for deployment
* Secret management services for production

When rendering AI-generated Markdown as HTML, an HTML sanitizer should also be considered for production deployments.
